Welchen Chip hat mein Mac? Klicke oben links auf das Apple-Menü → Über diesen Mac. Steht bei „Chip“ Apple M1 (oder M2, M3, M4), nimm Apple Silicon. Steht bei „Prozessor“ Intel, nimm die Intel-Version.

Installation auf Android

  1. APK herunterladen

    Öffne diese Website auf dem Handy und tippe bei Android auf APK herunterladen. Chrome fragt eventuell „Datei trotzdem herunterladen?“ – tippe auf Herunterladen.

  2. Datei öffnen

    Tippe auf die Download-Meldung oder öffne die App Dateien → Downloads → Schulplan.apk.

  3. Installation erlauben

    Beim ersten Mal erscheint „Aus Sicherheitsgründen kann dein Smartphone keine unbekannten Apps installieren“. Tippe auf Einstellungen, aktiviere Dieser Quelle vertrauen bzw. Apps aus dieser Quelle zulassen und gehe zurück.

  4. Installieren

    Tippe auf Installieren. Meldet Google Play Protect „App nicht bekannt“, tippe auf Mehr Details → Trotzdem installieren.

  5. Öffnen

    Tippe auf Öffnen. Schulplan liegt nun bei deinen Apps. Erlaube die Benachrichtigungen, wenn die App fragt – sonst bekommst du keine Erinnerungen.

Die Menüs heißen je nach Hersteller etwas anders (Samsung: „Unbekannte Apps installieren“, Xiaomi: „Unbekannte Quellen“). Gemeint ist immer dieselbe Erlaubnis für den Browser oder die Dateien-App.

Installation unter Windows

  1. Installer herunterladen

    Lade Schulplan-Setup.exe (76 MB). Meldet der Browser „wird nicht häufig heruntergeladen“, klicke auf die drei Punkte → Beibehalten.

  2. Doppelklicken

    Öffne die Datei aus dem Download-Ordner.

  3. SmartScreen bestätigen

    Erscheint „Der Computer wurde durch Windows geschützt“, klicke auf Weitere Informationen und dann auf Trotzdem ausführen. Die Meldung kommt, weil die App nicht mit einem kostenpflichtigen Zertifikat signiert ist.

  4. Fertig

    Schulplan installiert sich in wenigen Sekunden – ohne Administratorrechte – und startet von selbst. Ein Symbol liegt auf dem Desktop und im Startmenü.

Gut zu wissen

  • Schließt du das Fenster, läuft Schulplan unten rechts im Infobereich weiter, damit Erinnerungen ankommen. Rechtsklick auf das Symbol → Beenden schließt die App ganz.
  • Deine Daten liegen unter %APPDATA%\Schulplan, inklusive täglicher Sicherungen der letzten 14 Tage.
  • Team-Dateien, Einladungen und Sicherungen kannst du einfach mit der Maus ins Fenster ziehen.

Windows: „Smart App Control hat eine App blockiert“

Auf manchen Windows-11-PCs ist Smart App Control eingeschaltet. Es lässt nur Programme starten, die mit einem gekauften Zertifikat signiert sind oder die Microsoft bereits kennt. Schulplan wird kostenlos verteilt und hat (noch) kein solches Zertifikat. Anders als bei der SmartScreen-Meldung gibt es hier keinen „Trotzdem ausführen“-Knopf. Die Installation selbst hat trotzdem geklappt – nur der Start wird verhindert.

Lösung 1 (empfohlen): Web-App nutzen

Öffne die Web-App in Edge oder Chrome und installiere sie dort als App. Sie bekommt ein eigenes Fenster und ein Symbol auf dem Desktop und wird von Smart App Control nicht blockiert. Danach kannst du Schulplan über Einstellungen → Apps → Installierte Apps wieder deinstallieren.

Lösung 2: Smart App Control ausschalten

  1. Windows-Sicherheit öffnen

    Start → „Windows-Sicherheit“ eingeben und öffnen.

  2. App- & Browsersteuerung

    Links App- & Browsersteuerung → Smart App Control-Einstellungen.

  3. Ausschalten

    Aus wählen und Schulplan über das Desktop-Symbol starten.

Smart App Control ist ein zusätzlicher Schutz. Je nach Windows-Version lässt es sich nach dem Ausschalten nur durch Zurücksetzen von Windows wieder einschalten. Der normale Virenschutz (Microsoft Defender) bleibt aktiv. Auf Dienstgeräten entscheidet die IT der Schule – nutze dort die Web-App.

Installation auf dem Mac

  1. Passende Datei laden

    Apple Silicon (M1–M4) oder Intel – siehe Welche Version brauche ich?

  2. Entpacken

    Doppelklicke die ZIP-Datei im Download-Ordner. Es erscheint Schulplan.

  3. In „Programme“ ziehen

    Ziehe Schulplan in den Ordner Programme (in der Finder-Seitenleiste).

  4. Beim ersten Mal öffnen

    Klicke mit der rechten Maustaste (oder ctrl + Klick) auf Schulplan → Öffnen → Öffnen. Unter neueren macOS-Versionen: Systemeinstellungen → Datenschutz & Sicherheit → ganz unten Dennoch öffnen.

„Schulplan ist beschädigt und kann nicht geöffnet werden“? Das zeigt macOS bei Apps ohne Apple-Signatur. Öffne das Programm Terminal und gib einmalig ein: xattr -cr /Applications/Schulplan.app – danach startet die App normal.
  • Schließt du das Fenster, bleibt Schulplan im Dock aktiv. ⌘ Q beendet die App.
  • Mit ⌘ 1 bis 4 springst du zu Heute, Stundenplan, Klassen und Kalender.
  • Deine Daten liegen unter ~/Library/Application Support/Schulplan.
  • Beim ersten QR-Scan bzw. bei der Lautstärke-Ampel fragt macOS nach Kamera bzw. Mikrofon.

Installation unter Linux

Für Linux gibt es zwei Dateien. Nimm das .deb-Paket für Ubuntu, Linux Mint, Debian, Zorin OS, elementary OS und Pop!_OS. Für alle anderen Systeme (Fedora, openSUSE, Arch, Manjaro …) nimm das AppImage.

.deb-Paket (Ubuntu, Mint, Debian)

  1. Herunterladen

    Lade Schulplan-Linux.deb (70 MB) in deinen Download-Ordner.

  2. Installieren

    Doppelklicke die Datei. Je nach System öffnet sich das App-Zentrum, die Anwendungsverwaltung oder der Paket-Installer. Klicke auf Installieren und gib dein Passwort ein.

  3. Oder im Terminal

    Öffne das Terminal im Download-Ordner und gib ein: sudo apt install ./Schulplan-Linux.deb

  4. Starten

    Schulplan findest du jetzt im Anwendungsmenü (Suche: „Schulplan“). Tipp: Rechtsklick auf das Symbol im Dock → Zu Favoriten hinzufügen.

AppImage (alle Linux-Systeme)

  1. Herunterladen

    Lade Schulplan-Linux.AppImage (78 MB). Am besten legst du die Datei in einen festen Ordner, zum Beispiel ~/Anwendungen.

  2. Ausführbar machen

    Rechtsklick auf die Datei → Eigenschaften → Als Programm ausführen bzw. Ausführbar einschalten. Im Terminal: chmod +x Schulplan-Linux.AppImage

  3. Starten

    Doppelklicke die Datei. Updates ersetzen genau diese Datei – lass sie deshalb am selben Ort.

Das AppImage startet nicht? Unter Ubuntu 22.04 und neuer fehlt oft das Paket für FUSE. Installiere es einmalig im Terminal: sudo apt install libfuse2 (Ubuntu 24.04: sudo apt install libfuse2t64) – oder nimm einfach das .deb-Paket.

Gut zu wissen

  • Schließt du das Fenster, läuft Schulplan im Hintergrund weiter, damit Erinnerungen ankommen. Zurück kommst du über das Schulplan-Symbol in der oberen Leiste (falls dein System es anzeigt) oder indem du Schulplan einfach noch einmal öffnest. Strg Q beendet die App ganz.
  • Mit Alt blendest du die Menüleiste ein. Strg 1 bis 4 springen zu Heute, Stundenplan, Klassen und Kalender.
  • Deine Daten liegen unter ~/.config/Schulplan, inklusive täglicher Sicherungen der letzten 14 Tage.
  • Team-Dateien, Einladungen und Sicherungen kannst du einfach mit der Maus ins Fenster ziehen.

iPhone & iPad

Auf iPhone und iPad installierst du Schulplan als Web-App. Sie erscheint wie eine normale App auf dem Home-Bildschirm, startet ohne Browserleiste und funktioniert auch offline.

  1. In Safari öffnen

    Öffne die Schulplan-Web-App in Safari (nicht in Chrome oder in der Instagram-/WhatsApp-Vorschau).

  2. Teilen tippen

    Tippe unten (iPhone) bzw. oben (iPad) auf Teilen – das Quadrat mit dem Pfeil nach oben.

  3. Zum Home-Bildschirm

    Wische etwas nach unten und tippe auf Zum Home-Bildschirm, dann oben rechts auf Hinzufügen.

  4. Starten

    Öffne Schulplan ab jetzt über das neue Symbol. Unter Einstellungen → Zahl am App-Symbol zeigt das Symbol fällige Aufgaben an (dafür einmal Mitteilungen erlauben).

Widgets für den iPhone-Startbildschirm, Erinnerungen zu festen Uhrzeiten und eine App aus dem App Store gibt es nur für native Apps, die Apple im App Store prüft. Dafür sind ein Apple-Entwicklerkonto und ein Mac nötig – das ist für Schulplan derzeit nicht vorhanden.

Web-App (im Browser)

Die Web-App ist Schulplan ohne Installationsdatei. Sie läuft in jedem aktuellen Browser, lässt sich als App installieren, funktioniert offline und aktualisiert sich beim Öffnen von selbst. Adresse: Web-App öffnen.

Windows und Mac mit Edge oder Chrome

  1. Web-App öffnen

    Öffne die Web-App in Microsoft Edge oder Google Chrome.

  2. Als App installieren

    Edge: Menü ⋯ → Apps → Diese Website als App installieren. Chrome: Symbol Installieren rechts in der Adressleiste (oder Menü ⋮ → Streamen, speichern und teilen → Seite als App installieren).

  3. Aufs Desktop legen

    Bestätige „Auf dem Desktop anheften“ bzw. „Desktopverknüpfung erstellen“. Schulplan öffnet sich jetzt in einem eigenen Fenster.

iPhone und iPad

  1. In Safari öffnen

    Öffne die Web-App in Safari.

  2. Zum Home-Bildschirm

    Tippe auf Teilen (Quadrat mit Pfeil) → Zum Home-Bildschirm → Hinzufügen.

Gut zu wissen

  • Die Daten der Web-App liegen im jeweiligen Browser auf deinem Gerät. Löscht du die Browserdaten für die Seite, sind sie weg – exportiere deshalb regelmäßig eine Sicherung.
  • Die Daten sind getrennt von der Android-, Windows- oder Mac-App. Zum Übertragen eine Sicherung exportieren und in der Web-App wiederherstellen.
  • Erinnerungen und Widgets gibt es nur in den installierten Apps. Die Web-App kann Benachrichtigungen nur zeigen, solange sie geöffnet ist.

Erste Schritte

Beim ersten Öffnen gibst du deinen Namen und dein Notensystem an. Danach ist die App leer und gehört ganz dir: Die Karte Willkommen bei Schulplan auf der Startseite führt dich durch die ersten Schritte.

  1. Klassen anlegen

    Klassen → + Klasse. Gib Namen, Raum und deine Fächer an. Ein neues Fach kannst du direkt im selben Formular anlegen. Für die Oberstufe stellst du bei der Klasse „Punkte 0–15“ ein.

  2. Schüler:innen eintragen

    In der Klasse auf Liste einfügen tippen und Namen untereinander einfügen („Vorname Nachname“ oder „Nachname, Vorname“) – oder eine CSV-Datei aus der Schulverwaltung importieren.

  3. Stundenraster einstellen

    Einstellungen → Stundenraster. Mit Automatisch erzeugst du Zeiten aus Beginn, Stundenlänge und Pausen.

  4. Stundenplan eintragen

    Stundenplan → Stift oben rechts → leeres Feld antippen → Klasse, Fach und Raum wählen. „Doppelstunde“ trägt die folgende Stunde gleich mit ein.

  5. Ferien eintragen

    Kalender → ⋯ → Ferien eintragen. In Ferien zeigt der Stundenplan keinen Unterricht. Zur Begrüßung gibt es eine kleine Fest-Animation.

Stundenplan & Vertretungen

  • A/B-Wochen: unter Einstellungen → Stundenraster einschalten und angeben, ob diese Woche eine A- oder B-Woche ist. Beim Eintragen einer Stunde wählst du dann „Jede Woche“, „A-Woche“ oder „B-Woche“.
  • Änderungen: Ausfall, Raumänderung, eigene Vertretung oder Verlegung trägst du über Stundenplan → ⋯ → Änderung eintragen ein – oder direkt in der Stunde über das Menü.
  • Vertretungen im Kollegium erscheinen automatisch in deinem Plan, wenn du als Vertretung eingetragen bist (siehe Kollegium).
  • Drucken: Stundenplan → ⋯ → Stundenplan drucken (auf dem Handy auch als PDF speichern).

Eine Stunde halten

Tippe im Stundenplan oder auf der Startseite auf eine Stunde. Dort findest du alles für genau diese Stunde:

  • Letzte Stunde: Thema und Hausaufgabe der vorigen Stunde dieser Klasse.
  • Klassenbuch: Thema, Verlauf und Status (geplant, gehalten, ausgefallen). Wird automatisch gespeichert.
  • Hausaufgabe aufgeben: Text eingeben – als Fälligkeit ist die nächste Stunde dieser Klasse vorgeschlagen.
  • Anwesenheit: „Alle anwesend“ oder einzelne Schüler:innen als fehlend markieren.
  • Mitarbeit: + und – je Kind; unter „⋯“ auch „Hausaufgabe vergessen“, „Material vergessen“, Lob oder eine Notiz.

Noten & Leistungsnachweise

  1. Leistungsnachweis anlegen

    Klasse → Noten → + Leistung. Wähle die Kategorie (z. B. Klassenarbeit, Test, Mündlich), Datum und Gewicht.

  2. Mit Punkten bewerten (optional)

    Trägst du eine maximale Punktzahl ein, gibst du pro Kind nur die Punkte ein – die Note berechnet der Notenschlüssel. Den Schlüssel änderst du für alle Arbeiten unter Einstellungen → Notenschlüssel oder nur für diese Arbeit.

  3. Noten eintippen

    Ohne Punkte tippst du die Note direkt ein, z. B. 2-, 3+, 2,5 oder 11 (Punkte). Schneller geht es mit der Notentafel: auf einen Namen tippen und die Note wählen – die App springt zum nächsten Kind.

  4. Auswerten

    Notenspiegel, Durchschnitt und der Anteil der Fünfen und Sechsen stehen oben. Liegt er über einem Drittel, weist die App auf eine mögliche Genehmigungspflicht hin.

Die Gewichtung legst du je Kategorie fest (z. B. schriftlich 50 %, mündlich 25 %); pro Klasse lässt sie sich abweichend einstellen (Klasse → Info → Gewichtung). In der Notentabelle zeigt die Spalte „Note“ die gerundete Empfehlung; antippen setzt eine eigene Zeugnisnote. Export als CSV für Excel und Druck sind unten in der Tabelle.

Anwesenheit

  • Erfassen über die Stunde, über die Startseite oder Klasse → Anwesenheit → Heute erfassen.
  • Status: U unentschuldigt, E entschuldigt, V verspätet (mit Minuten), B beurlaubt. Ein Tipp auf den Namen öffnet Notiz und Minuten.
  • Die Statistik zeigt je Kind Fehlstunden, Verspätungen und die Anwesenheitsquote – für Schuljahr, Halbjahre oder alles. Export als CSV.

Hausaufgaben, Aufgaben & Kalender

  • Hausaufgaben: nach Fälligkeit sortiert. Mit Kontrolle markierst du, wer sie nicht hat – das erscheint im Schülerprofil.
  • Aufgaben: deine To-dos mit Priorität, Kategorie, Uhrzeit und Wiederholung. Neue Aufgabe einfach oben eintippen und Enter drücken.
  • Abhaken: Tippst du auf den Kreis vor einer Aufgabe oder Hausaufgabe, erscheint der Haken und du wählst: Erledigt, Nicht geschafft (Aufgaben auf morgen, Hausaufgaben auf die nächste Stunde), Bearbeiten, Löschen oder Haken wieder entfernen.
  • Kalender: Monats- und Listenansicht mit Terminen, Prüfungen, Hausaufgaben, Aufgaben und Geburtstagen. Termine kannst du als .ics für Google Kalender oder Outlook exportieren.
  • Notizen: farbig, anheftbar, mit Checklisten (- [ ] Punkt) und einer Klasse zuordenbar.
  • Elterngespräche: Protokoll mit Vereinbarungen und Wiedervorlage, druckbar mit Unterschriftenfeld.

Kollegium

Unter Mehr → Kollegium arbeitest du mit Kolleg:innen deiner Schule zusammen. Geteilt werden Schwarzes Brett, Kollegiumsliste, gemeinsame Termine und Ferien, Vertretungen und – wenn du willst – Klassenlisten. Noten, Fehlzeiten, Beobachtungen und Notizen bleiben immer privat.

Team gründen und einladen

  1. Schulteam gründen

    Eine Person tippt auf Schulteam gründen, gibt den Namen der Schule und das eigene Profil (Kürzel, Fächer) an.

  2. Einladen

    Einladen zeigt drei Wege: einen QR-Code für das Lehrerzimmer, eine Nachricht mit verschlüsseltem Code (für WhatsApp oder E-Mail) und das Weitergeben der App selbst.

  3. PIN getrennt sagen

    Die Nachricht ist mit einer vierstelligen PIN geschützt. Sag die PIN persönlich oder am Telefon, nicht in derselben Nachricht.

Einer Einladung beitreten

Mehr → Kollegium → Einladung annehmen → QR-Code scannen, Einladungs-Nachricht einfügen oder Datei öffnen.

  1. Nachricht kopieren

    Halte die Einladungs-Nachricht im Messenger gedrückt → Kopieren. Kopiere die ganze Nachricht – der Einladungscode ist ein langer Text, der mit SO1J. beginnt.

  2. Einfügen

    Tippe in Schulplan auf Aus der Zwischenablage einfügen (oder lange ins Feld drücken → Einfügen).

  3. PIN eingeben

    Gib die vierstellige PIN (z. B. 2489), die dir die Kollegin persönlich gesagt hat, in das Feld PIN ein. Die PIN allein reicht nicht – sie gehört immer zur Nachricht.

Danach dein Profil ausfüllen und auf Wunsch Schuljahr, Stundenraster und Ferien der Schule übernehmen. Sende anschließend deine Antwort, damit dich das Kollegium sieht.

Abgleichen

  • Per Datei: „Senden“ teilt eine verschlüsselte Team-Datei (z. B. in eurer Kollegiums-Gruppe), „Empfangen“ bzw. das Öffnen der Datei übernimmt die Neuigkeiten.
  • Gemeinsame Cloud-Datei: Lege eine Team-Datei in einem freigegebenen Ordner an (Schul-Nextcloud, OneDrive, Google Drive). Alle verbinden dieselbe Datei; die App gleicht dann beim Öffnen und nach Änderungen selbst ab.

Im Team

  • Schwarzes Brett: Beiträge an alle, auf Wunsch als wichtig markiert oder angeheftet.
  • Vertretung zuweisen: siehe unten – auf Wunsch bekommt nur die Vertretung die Meldung.
  • Vertretungsplan: Bist du als Vertretung eingetragen, steht die Stunde in deinem Stundenplan; bei der abwesenden Lehrkraft wird sie als vertreten markiert. „Ich übernehme“ trägt dich mit einem Tipp ein.
  • Klassenlisten: Die Klassenleitung teilt die Liste (wahlweise mit Elternkontakten), Fachlehrkräfte übernehmen sie mit einem Tipp – später auch Änderungen.
  • Abwesenheit melden: Krank, Fortbildung oder Klassenfahrt? Kollegium → Abwesend → Abwesenheit melden. Deine betroffenen Stunden aus dem Stundenplan gehen automatisch an die Vertretungsplanung.
  • Mitteilungen der Schulleitung: erscheinen hervorgehoben auf dem Schwarzen Brett und auf der Startseite. Fordert die Schulleitung eine Lesebestätigung an, tippst du auf Gelesen – bestätigen.

Vertretung zuweisen

Kurzanleitung, 35 Sekunden

  1. Vertretung eintragen

    Mehr → Kollegium → Vertretungen → + Vertretung. Datum, Stunde, Klasse, abwesende Lehrkraft und die Vertretung wählen.

  2. Wer bekommt die Meldung?

    Nur die Vertretung: Die Stunde sehen nur die Vertretung, die abwesende Lehrkraft und die Schulleitung – alle anderen bekommen nichts mit. Oder Ganzes Kollegium, dann sehen es alle.

  3. Meldung senden

    Nach dem Speichern auf Meldung jetzt senden tippen und WhatsApp, E-Mail oder einen anderen Weg wählen. Mit gemeinsamer Cloud-Datei kommt die Meldung auch automatisch beim nächsten Abgleich an.

  4. Fertig

    Die Kollegin öffnet die Datei in Schulplan und sieht groß „Du vertrittst …“ mit Tag, Stunde, Klasse und Raum. Die Stunde steht automatisch in ihrem Stundenplan.

Hinweis: Die Vertretung ist im verschlüsselten Team-Abgleich enthalten, Schulplan zeigt sie aber nur den Beteiligten an. Offene Vertretungen (noch ohne Person) gehen immer an alle, damit jemand „Ich übernehme“ tippen kann.

Aufsicht, Räume & Umfragen

Diese Bereiche findest du unter Mehr → Kollegium in den Reitern Aufsicht, Räume und Umfragen.

Pausenaufsicht

  • Die Schulleitung plant die Aufsichten für die Woche: Pause, Uhrzeit, Ort und Lehrkraft – auf Wunsch für mehrere Wochentage auf einmal.
  • Jede Lehrkraft sieht ihre Aufsichten auf der Startseite unter Heute außerdem und wird 5 Minuten vorher erinnert.
  • Fehlt jemand, zeigt das Cockpit der Schulleitung Aufsichten ohne Lehrkraft. Mit Vertreten übernimmt eine andere Lehrkraft nur an diesem Tag – der Wochenplan bleibt gleich.
  • Ist eine Schulleitung eingetragen, kann nur sie den Plan ändern; ihre Einträge sind digital unterschrieben.

Räume buchen

  • Die Schulleitung legt buchbare Räume an, zum Beispiel Computerraum, Aula oder Sporthalle.
  • Jede Lehrkraft öffnet einen Raum, sieht die Wochenübersicht und tippt auf ein freies Feld, um eine Stunde zu buchen. Eigene Buchungen lassen sich wieder freigeben.
  • Buchen zwei Personen gleichzeitig ohne Abgleich, markiert Schulplan das Feld als doppelt; die frühere Buchung gilt.

Umfragen

  • Jede Lehrkraft kann eine Umfrage starten: Frage, Antworten (eine pro Zeile), optional Frist, mehrere Antworten oder „Namen nicht anzeigen“.
  • Offene Umfragen erscheinen auf der Startseite mit Jetzt abstimmen; die Ergebnisse siehst du sofort.
  • Die Schulleitung sieht in ihrem Cockpit, wer noch nicht abgestimmt hat, und kann Umfragen beenden oder das Ergebnis teilen.

Statistik für die Schulleitung

Im Cockpit unter Statistik: Vertretungen gehalten und benötigt, Abwesenheitstage (nur Schultage), Aufsichten pro Woche und gelesene Mitteilungen je Lehrkraft – als CSV-Tabelle exportierbar.

Chat & Storys

Den Chat findest du unter Mehr → Chat oder auf der Startseite. Er ist Teil des Schulteams – alle Kolleg:innen brauchen Schulplan 1.8 oder neuer.

  • Einzelchat: Neuer Chat → Nachricht an … und eine Person wählen. Gruppe: Neuer Chat → Neue Gruppe, Name, Symbol und Mitglieder wählen. Der Chat Ganzes Kollegium erreicht alle.
  • Emojis über den Smiley-Knopf, Fotos über den Upload-Knopf (werden automatisch verkleinert), Sprachnachrichten über das Mikrofon (bis 2 Minuten). Tippe auf eine Nachricht für Reaktionen, Kopieren oder „Für alle löschen“.
  • Anrufen (Telefonsymbol) öffnet die Telefon-App, wenn die Person eine Nummer im Profil hat. Videoanruf schickt allen im Chat einen Link zu einem Videoraum und öffnet ihn.
  • Storys: Tippe oben auf „Deine Story“ – Text mit Farbe oder ein Foto, sichtbar für das ganze Kollegium und nach 24 Stunden weg.
  • Zustellung: Nachrichten kommen über den Team-Abgleich. Mit verbundener Cloud-Datei gleicht Schulplan bei geöffnetem Chat alle 15 Sekunden ab, sonst beim Öffnen der App. Ohne Cloud-Datei teilst du Neuigkeiten mit „Senden“. Neue Nachrichten melden sich mit einer Benachrichtigung – ohne den Inhalt zu zeigen.
Jede Nachricht wird nur für die Mitglieder des Chats verschlüsselt. Wer später dazukommt, kann ältere Nachrichten nicht lesen. Nachrichten werden nach 30 Tagen automatisch gelöscht, damit die Team-Datei klein bleibt. Einen Live-Messenger mit eigenem Server ersetzt der Chat nicht.

Assistent & KI-Modus

Den Assistenten öffnest du über das ✨-Symbol auf der Startseite oder unter Mehr → Assistent. Ohne Einstellungen arbeitet er offline und versteht zum Beispiel:

  • „Erinnere mich morgen um 7 an die Kopien“ · „Erinnere mich in 20 Minuten an den Elternbrief“
  • „Erstelle Aufgabe Klassenarbeit korrigieren bis Freitag“ · „Erledige Aufgabe Klassenarbeit“

KI-Modus mit Claude

  1. API-Schlüssel besorgen

    Lege unter console.anthropic.com ein Konto an und erstelle einen API-Schlüssel (beginnt mit sk-ant-). Die Nutzung wird dort pro Anfrage abgerechnet.

  2. Einschalten

    Im Assistenten oben rechts auf das Zahnrad → KI-Modus wählen, den Schlüssel einfügen und speichern. Voreingestellt ist Claude Opus 5.5; Sonnet 5.5 und Haiku 5.5 sind schneller und günstiger.

  3. Fragen

    Jetzt versteht der Assistent auch freie Fragen und mehrere Aufträge auf einmal. Bevor er etwas löscht, fragt die App dich um Erlaubnis.

Im KI-Modus gehen deine Fragen und die nötigen Einträge an Anthropic (siehe Datenschutz). Schülerdaten gibt der Assistent nur weiter, wenn du „Schülerdaten freigeben“ einschaltest – prüfe vorher die Vorgaben deiner Schule.

Fest-Animationen

Wenn du Ferien oder einen Festtag einträgst, begrüßt dich Schulplan kurz mit einer Animation. Welche, richtet sich nach dem Titel – sonst nach der Jahreszeit:

  • Sommerferien: eine lachende Sonne mit Sonnenbrille und Meereswellen
  • Oster-, Frühjahrs- und Pfingstferien: Blumen wachsen, Schmetterlinge fliegen, Blüten fallen
  • Herbstferien: bunte Blätter fallen
  • Halloween (auch als Termin, z. B. „Halloween-Party“): Mond, Fledermäuse, ein Geist und leuchtende Kürbisse
  • Weihnachts- und Winterferien: Schnee, ein Weihnachtsbaum mit Lichtern und Geschenke

Antippen beendet die Animation sofort. Unter Einstellungen → Fest-Animationen kannst du sie dir als Vorschau ansehen oder ganz ausschalten – im Lehrer- und im Schulleitermodus.

Schulleitermodus

Der Schulleitermodus gibt der Schulleitung mehr Kontrolle über die Schulorganisation in Schulplan. Er ist in jeder Version enthalten und wird mit eigenen Zugangsdaten geöffnet.

  1. Anmelden

    Mehr → Schulleitermodus (oder Einstellungen → Schulleitermodus) öffnen, Name und Passwort der Schulleitung eingeben.

  2. Zugangsdaten ändern

    Direkt nach der ersten Anmeldung unter Einstellungen → Schulleitermodus → Zugangsdaten ändern einen eigenen Namen und ein eigenes Passwort festlegen. Die Zugangsdaten gelten für dieses Gerät und werden nur verschlüsselt gespeichert.

  3. Im Kollegium eintragen

    Im Cockpit auf Als Schulleitung eintragen tippen. Ab dann unterschreibt dein Gerät deine verbindlichen Einträge digital – es kann immer nur eine Schulleitung geben.

Das Cockpit

  • Überblick: Kollegium, heute abwesende Lehrkräfte, offene Vertretungen und die nächsten Schultermine.
  • Termin für alle: Konferenzen, Elternsprechtage oder Fristen als verbindlichen Termin – auf Wunsch als Pflichttermin mit Erinnerung am Vortag.
  • Mitteilung an alle: hervorgehoben auf dem Schwarzen Brett, auf Wunsch mit Lesebestätigung. Du siehst, wer schon gelesen hat.
  • Abwesenheiten & Vertretungen: Meldet eine Lehrkraft sich ab, siehst du ihre betroffenen Stunden und planst jede Vertretung mit einem Tipp.
  • Schulvorgaben: Schuljahr, Stundenraster und Fächer verbindlich für alle – die Geräte im Kollegium übernehmen sie automatisch. Ferien legst du als verbindliche Termine fest.
  • Jahresplanung: alle Schultermine des Schuljahres nach Monaten, als Kalenderdatei exportierbar.
  • Kollegium verwalten: Funktionen, Abwesenheiten und Lesebestätigungen je Person, Mitglieder entfernen, die Schulleitung übergeben.
Verbindliche Einträge der Schulleitung sind digital unterschrieben. Andere Geräte können sie weder ändern noch löschen oder fälschen. Ein kurzes Sicherheitsmerkmal (z. B. K7QF-2MXA) unter Einstellungen → Schulleitermodus ist auf allen Geräten gleich. Damit alle die neuen Funktionen sehen, sollte das ganze Kollegium Version 1.5 oder neuer nutzen.

Widgets

Windows, Mac und Linux: Desktop-Widget

Ein kleines Fenster auf dem Desktop zeigt die laufende oder nächste Stunde mit Restzeit, die heutigen Stunden, offene Aufgaben und die nächste Prüfung. Es aktualisiert sich von selbst.

  • Einschalten: Einstellungen → Desktop-Widget, unter Windows auch per Rechtsklick auf das Schulplan-Symbol im Infobereich, am Mac über Fenster → Desktop-Widget anzeigen (⌘ ⇧ W), unter Linux mit Strg ⇧ W oder über Datei → Desktop-Widget anzeigen.
  • Verschieben: oben am Titel ziehen. Größe: am Rand ziehen. Position und Größe merkt sich Schulplan.
  • Die Stecknadel hält das Widget immer im Vordergrund; das Kreuz blendet es aus. Ein Klick auf einen Eintrag öffnet ihn in Schulplan.

Android: Startbildschirm

Lange auf das Schulplan-Symbol drücken → Widgets (oder lange auf eine freie Stelle des Startbildschirms → Widgets → Schulplan). Es gibt vier Widgets:

  • Stundenplan heute – alle Stunden mit Raum und Uhrzeit, die laufende ist markiert.
  • Nächste Stunde – klein und lila: was gerade läuft oder als Nächstes kommt.
  • Aufgaben – offene Aufgaben nach Fälligkeit.
  • Termine & Prüfungen – was in den nächsten Wochen ansteht.

Werkzeuge

Unter Mehr → Werkzeuge: Zufallsauswahl (ohne Wiederholung, Abwesende werden übersprungen), Gruppen bilden, Timer und Stoppuhr, Lautstärke-Ampel über das Mikrofon (es wird nichts aufgenommen), Ampel für Arbeitsphasen, Notenschlüssel- und Notenrechner, Würfel und Stundenuhr. Den Sitzplan findest du in jeder Klasse.

Datensicherung & Gerätewechsel

  1. Sicherung exportieren

    Mehr → Datensicherung → Sicherung exportieren. Speichere die Datei an einem sicheren Ort, z. B. auf einem dienstlichen Speicher.

  2. Auf das neue Gerät bringen

    Per Kabel, USB-Stick, Cloud-Ordner oder E-Mail an dich selbst.

  3. Wiederherstellen

    Auf dem neuen Gerät Datensicherung → Sicherung wiederherstellen und die Datei wählen. Am Computer kannst du sie auch ins Fenster ziehen.

Zusätzlich legt die App täglich eine automatische Sicherung auf dem Gerät an (die letzten 14 Tage). Sie hilft bei Bedienfehlern, aber nicht bei Verlust des Geräts.

Sicherungsdateien enthalten alle Daten unverschlüsselt, auch Noten und Kontaktdaten. Bewahre sie so sorgfältig auf wie eine Notenliste aus Papier.

Updates

  • Schulplan prüft beim Öffnen und etwa zweimal täglich auf eine neue Version und zeigt dann „Neue Version verfügbar“ mit allen Neuerungen.
  • Android: „Jetzt aktualisieren“ → einmalig „Apps aus dieser Quelle zulassen“ → „Aktualisieren“.
  • Windows: „Jetzt aktualisieren“ – Schulplan installiert sich still neu und startet wieder.
  • Mac: Die neue Version landet im Download-Ordner; entpacken und in „Programme“ ersetzen.
  • Linux (AppImage): „Jetzt aktualisieren“ – die Datei wird ersetzt und Schulplan startet neu, ganz ohne Passwort.
  • Linux (.deb): „Jetzt aktualisieren“ – dein System fragt einmal nach deinem Passwort, dann startet Schulplan in der neuen Version.
  • Nach einem Update zeigt die App, was neu ist. Deine Daten bleiben immer erhalten. Die Suche bricht nach spätestens 15 Sekunden ab.

PIN & Datenschutz-Einstellungen

  • Einstellungen → App-Sperre (PIN): 4–6 Ziffern. Wähle, wann die App sich wieder sperrt (sofort bis nach einer Stunde).
  • Bildschirmfotos verhindern blendet den Inhalt in Screenshots und in der App-Übersicht aus.
  • Die PIN lässt sich nicht zurücksetzen. Vergisst du sie, hilft nur eine Neuinstallation mit deiner letzten Sicherung.

Hilfe bei Problemen

Android: „App wurde nicht installiert“

Meist ist eine ältere Version mit anderer Signatur installiert oder der Speicher ist voll. Exportiere zuerst eine Sicherung, deinstalliere die alte App und installiere neu. Prüfe außerdem, ob die Datei vollständig heruntergeladen wurde (1,8 MB).

Ich bekomme keine Erinnerungen

Prüfe unter Einstellungen → Benachrichtigungen, ob sie eingeschaltet sind, und in den Android-Einstellungen, ob Schulplan Mitteilungen senden darf. Nimm Schulplan bei Bedarf vom Akku-Sparen aus. Am Computer muss Schulplan laufen (Infobereich bzw. Dock).

Die Update-Suche meldet „keine Antwort vom Server“

Das Gerät ist offline oder ein Schulnetz blockiert die Verbindung. Versuche es später oder in einem anderen Netz. Nach einer Veröffentlichung kann es bis zu fünf Minuten dauern, bis die neue Version angezeigt wird.

Windows: Das Update bleibt bei „Wird installiert …“ stehen

Das konnte bis Version 1.4.2 passieren, wenn der Virenschutz die neue Datei gerade prüfte. So geht es weiter: Klicke unten rechts im Infobereich (eventuell unter ^) mit der rechten Maustaste auf das Schulplan-Symbol → Beenden. Lade dann Schulplan-Setup.exe von dieser Website und doppelklicke sie – die neue Version wird einfach drüber installiert, deine Daten bleiben erhalten. Ab Version 1.4.3 versucht Schulplan die Installation selbst mehrmals und läuft auch weiter, wenn du das Fenster schließt.

Windows: Der Installer startet nicht

Bestätige die SmartScreen-Meldung über „Weitere Informationen → Trotzdem ausführen“. Manche Virenscanner halten unbekannte Programme kurz an; prüfe dort die Quarantäne.

Linux: Das AppImage startet nicht

Prüfe, ob die Datei ausführbar ist (Rechtsklick → Eigenschaften → „Als Programm ausführen“). Unter Ubuntu 22.04 und neuer fehlt oft FUSE: sudo apt install libfuse2 bzw. unter Ubuntu 24.04 sudo apt install libfuse2t64. Alternativ das .deb-Paket nehmen – siehe Installation unter Linux.

Mac: „beschädigt“ oder „Entwickler nicht verifiziert“

Siehe Installation auf dem Mac: Rechtsklick → Öffnen, „Dennoch öffnen“ in den Systemeinstellungen oder einmalig xattr -cr /Applications/Schulplan.app im Terminal.

Die Kollegium-Einladung funktioniert nicht

Füge die ganze Nachricht ins obere Feld ein und die vierstellige PIN ins Feld PIN – die PIN allein reicht nicht. Meldet die App „Die PIN passt nicht“, frag noch einmal nach der PIN oder lass dir eine neue Einladung schicken. Ein QR-Code funktioniert nur in der Schulplan-App selbst (Kollegium → Einladung annehmen → QR-Code scannen).

Meine Frage ist nicht dabei

Stelle sie auf der Fragen-und-Fehler-Seite des Projekts. Schreibe dort bitte keine Schülerdaten oder persönlichen Angaben hinein.

Deinstallieren

  • Android: Symbol lange drücken → App-Info → Deinstallieren. Dabei werden alle Daten auf dem Gerät gelöscht – vorher eine Sicherung exportieren.
  • Windows: Einstellungen → Apps → Installierte Apps → Schulplan → Deinstallieren. Deine Daten in %APPDATA%\Schulplan bleiben erhalten; lösche den Ordner, wenn du alles entfernen willst.
  • Mac: Schulplan aus „Programme“ in den Papierkorb ziehen. Daten liegen in ~/Library/Application Support/Schulplan.
  • Linux: .deb im Terminal mit sudo apt remove schulplan entfernen, ein AppImage einfach löschen. Daten liegen in ~/.config/Schulplan.
